## Emerging patterns and improvement hypotheses

1. **A shared occasion is not event identity.** Prompts and examples must explicitly distinguish umbrella observances (for example, America 250 or Independence Day) from the independent events held under them.
2. **Judge-only attachment still fails when Item B has no content.** For cardless/nascent storylines, pass the latest member entry or episode card to the judge; do not represent a candidate as `(storyline)` plus tokens.
3. **Failing open to KNN causes high-impact theme contamination.** Theme-adjudicator errors should be split-biased (spawn/defer/retry), while nearest neighbors remain candidates only.
4. **Cold-start entity statistics make automatic episode gates unsafe.** Require adjudication for centroid/entity episode joins, or at minimum warm the entity EMA from the sampled corpus and blacklist ambient location/agency terms as identity evidence.
5. **Fallback metadata violates the naming and category contract.** Retry structured output, use a second model, or queue the theme for repair; do not persist headline-copy labels or null seeded categories as the final state.
6. **Merge recall depends on incidental candidate co-occurrence.** Add a separate post-assignment duplicate-theme pass over theme centroids/names, adjudicated by the LLM, rather than relying only on inline merge suggestions.

## Fixes implemented before the next rerun

1. Event keys, centroid similarity, and entity overlap now nominate entry-to-episode candidates only; every non-duplicate join requires an affirmative judge verdict. Content-hash and high-confidence near-duplicate folding remain deterministic.
2. Episode judges receive a real member entry instead of an `(episode)` placeholder, and cardless storyline judges receive the latest real storyline entry instead of `(storyline)` plus union tokens.
3. The same-event prompt now states that a shared holiday, anniversary, observance, or umbrella initiative belongs at the theme layer and is not event identity.
4. Theme-adjudicator failures are split-biased: they spawn a fully validated new theme or defer assignment. KNN is no longer allowed to make the final decision.
5. Theme metadata is retried twice and must contain both a valid 2–5 word label and a seeded category before persistence. Headline-copy and null-category fallbacks were removed; deferred storylines are retried at finalization and counted in experiment health.
6. Theme/category prompts now include broad-label counterexamples, durable-program examples, subject-over-agency guidance, and category boundary guidance for consumer/financial enforcement and cross-cutting veteran subjects.
7. Finalization now runs a separate name/headline/centroid candidate pass for duplicate themes. An LLM pair judge alone can merge them and select the canonical name/category.
